# Bundled fonts

The TrueType files in this directory are redistributed unmodified from
[Google Fonts](https://fonts.google.com). They are bundled so that text renders with
identical metrics in the browser preview and in server-side exports.

| Family | License |
| --- | --- |
| Inter, Montserrat, Poppins, Oswald, Bebas Neue, Anton, Archivo Black, Playfair Display, Merriweather, Lobster, Pacifico, Dancing Script, Permanent Marker | [SIL Open Font License 1.1](https://openfontlicense.org) |
| Roboto, Roboto Mono | [SIL Open Font License 1.1](https://openfontlicense.org) (formerly Apache License 2.0) |

The SIL Open Font License permits bundling, embedding and redistribution of the fonts with any
software, provided the fonts are not sold by themselves. Copyright notices are embedded in each
font file's `name` table.

Run `npm run fonts:download -- --force` to refresh the files from Google Fonts.
